Computer Network Applications

Application Name Network Protocol Description
World Wide Web (HTTP/HTTPS) HTTP / TCP Browsing websites and web pages across the internet.
Email (SMTP / IMAP) SMTP, POP3, IMAP Sending, receiving, and managing electronic mail.
File Transfer Protocol (FTP) FTP / TCP Transferring files between a client and a server.
Domain Name System (DNS) DNS / UDP, TCP Translating human-readable domain names into IP addresses.
Remote Desktop (RDP / SSH) RDP, SSH / TCP Accessing and controlling a computer or server remotely.
VoIP / Video Conferencing RTP, SIP / UDP Real-time voice and video communication over the network.
